# Gridori

日本の家屋向けの910mmグリッド式間取りツールです。
現在はプロトタイプです。

## 起動方法

`floorplan_910mm_prototype.html` をブラウザで開きます。隣の `model.js` も必要です。サーバーやビルドは不要です。

## 壁芯グリッドモデル

壁の座標はmm単位の壁芯始点、設定長は壁芯端点間の距離です。壁の実体は両端へ壁厚の半分ずつ延長され、全長は設定長＋壁厚になります。回転は始点を中心に行います。

- 壁をドラッグすると455mmグリッドへ吸着します。両端点から182mm以内の既存壁端点を優先し、それがなければ壁芯途中へ吸着します。オレンジの丸が接続位置です。
- 設定長・壁厚・角度・座標は右側で直接入力できます。長さは±455mmボタン、回転はR／Shift+Rでも操作できます。矢印キーは従来どおり91mmの微調整です。
- JSONはversion 3の壁芯モデルで保存します。従来のversion 2と、version 1のobjects形式を読み込めます。旧壁のwidthは設定長として変換し、x/yは維持します。

今回の対象は壁モデル統一とL字・T字接続のスナップです。接続は座標の一致で表現し、接続を維持した移動や端点ドラッグ編集、建具の壁への取り付けは未実装です。

## テスト

検証は `node --test model.test.js`。壁形状・スナップ・JSON互換性と、最小DOM環境で実際のSVG描画処理・既存操作を確認します。
